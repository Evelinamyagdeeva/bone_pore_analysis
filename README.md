# bone_pore_analysis
MATLAB pipeline for 3D segmentation and morphometric analysis of mouse bone microstructure and pore architecture from micro-CT data.
# 3D-сегментация костной ткани и анализ пористости

MATLAB-пайплайн для **3D-сегментации костной ткани мышей**, включая образцы, полученные после воздействия космической среды, и последующего количественного анализа костной микроструктуры и пористости.

Проект работает с объёмными данными микротомографии в формате `.VGI/.VOL` и позволяет получить:

* 3D-маску исследуемой кости;
* очищенную бинарную маску костной ткани;
* оценку внешней формы образца;
* 3D-маску пор;
* разделение отдельных пор методом Watershed;
* объём и радиус каждой поры;
* координаты центроидов;
* главные оси пор;
* ориентацию пор в пространстве;
* степень анизотропии;
* сферичность;
* число Эйлера;
* плотность связности;
* классификацию пор на открытые и закрытые;
* общие показатели BV/TV и пористости;
* визуализацию крупнейших пор;
* 3D-визуализацию ориентации пор относительно оси `Z`.

---

## 1. Общая схема обработки

Пайплайн состоит из нескольких последовательных этапов:

```text

     │
     ▼
Загрузка 3D-томограммы
     │
     ▼
Нормализация интенсивности
     │
     ▼
Автоматическая бинаризация
     │
     ▼
Поиск границ / контуров
     │
     ▼
Очистка и выделение костного объекта
     │
     ▼
boneMask
     │
     ▼
Построение 3D alpha-shape
     │
     ▼
Определение пространства пор
     │
     ▼
Удаление артефактов
     │
     ▼

     │
     ├───────────────┐

                   ▼

                   │
```

Исходные данные представлены парой файлов:


Файл `.VGI` содержит метаданные томограммы, включая размеры объёма и размер вокселя.

```text
control_2.vol
```


# 4. Загрузка 3D-томограммы

На первом этапе из `.VGI` считывается размер объёмного массива:

```matlab
vgi_file = 'control_2.vgi';

fid = fopen(vgi_file);

x = [];
y = [];
z = [];

while ~feof(fid)
    line = fgetl(fid);

    if contains(line, 'size =')
        num = sscanf(line, 'size = %d %d %d');

        x = num(1);
        y = num(2);
        z = num(3);
    end
end

fclose(fid);
```

После этого загружается `.VOL`:

```matlab
fid_vol = fopen('control_2.vol','r');

data = fread(fid_vol, x*y*z, '*uint16');

fclose(fid_vol);

volume = reshape(data, [x,y,z]);
volume = permute(volume, [2,1,3]);
```

Таким образом формируется исходный 3D-массив:

```matlab
volume(Y,X,Z)
```

---

# 5. Нормализация интенсивности

Для дальнейшей обработки данные преобразуются в `single` и нормализуются в диапазон `[0,1]`:

```matlab
V = single(volume);
V = mat2gray(V);
```

Это позволяет применять стандартные методы бинаризации независимо от абсолютного диапазона исходных значений.

---

# 6. Первичная сегментация

Для автоматического определения порога используется метод Otsu:

```matlab
level = graythresh(V);
```

После этого объём переводится в бинарный вид:

```matlab
V = V > level;
```

Полученная маска содержит области, соответствующие объектам с интенсивностью выше выбранного порога.

Для контроля результата используется:

```matlab
volshow(V);
```

---

# 7. Выделение границ

Для получения границ объекта используется пользовательская функция:

```matlab
sigma = 0.7;

V = single(V);

edges_labeled = my_kenny(V, sigma);
```

Функция `my_kenny` должна находиться в MATLAB path или в директории проекта.

Параметр:

```matlab
sigma = 0.7;
```

определяет степень сглаживания перед выделением границ.

# 8. Очистка бинарной маски

После первичной сегментации выполняется морфологическая обработка.

### Заполнение внутренних отверстий

```matlab
Vbin = imfill(Vbin, 26, 'holes');
```

### Удаление небольших объектов

```matlab
Vbin = bwareaopen(Vbin, 500);
```

Параметр `500` задаёт минимальный размер компоненты.

При необходимости его следует адаптировать под размер вокселя и масштаб конкретного набора данных.

# 9. Выделение костного объекта

Границы утолщаются морфологической операцией:

```matlab
se = strel('sphere', 2);

edges_fat = imdilate(edges, se);
```

После этого границы используются для ограничения области:

```matlab
mask = Vbin & ~edges_fat;
```

Из полученной маски выбирается крупнейшая связная компонента:

```matlab
CC = bwconncomp(mask, 26);

numPixels = cellfun(@numel, CC.PixelIdxList);

[~, idx] = max(numPixels);
```

Формируется итоговая маска кости:

```matlab
boneMask = false(size(mask));

boneMask(CC.PixelIdxList{idx}) = true;
```

Полученный объект визуализируется:

```matlab
VonlyBone = V;

VonlyBone(~boneMask) = 0;

volshow(VonlyBone);
```

И сохраняется:

```matlab
save('bone_cSCI_1.mat', 'VonlyBone', '-v7.3');
```

---

# 10. Построение внешней оболочки кости

Для определения потенциального пространства пор на каждом 2D-срезе строится `alphaShape`.

Для каждого среза:

```matlab
slice2D = boneMask(:,:,k);
```

извлекаются координаты костной ткани:

```matlab
[yPts, xPts] = find(slice2D);

points = [xPts, yPts];
```

После этого создаётся alpha-shape:

```matlab
shp = alphaShape(points, alphaValue);
```

В текущей реализации используется:

```matlab
alphaValue = 15;
```

Полученная область преобразуется обратно в бинарную маску:

```matlab
alpha_mask = inShape(shp, Xgrid, Ygrid);

alpha_mask = imfill(alpha_mask,'holes');
```

Все срезы объединяются в 3D-массив:

```matlab
hullVolume(:,:,k) = alpha_mask;
```

---

# 11. Первичное выделение пор

Разница между внешней оболочкой и реальной костной тканью используется для получения потенциального пространства пор:

```matlab
differenceVolume = hullVolume & ~boneMask;
```

То есть:

```text
hullVolume
    -
boneMask
    =
potential pore space
```

# 12. Удаление артефактов

Для удаления небольших или нежелательных компонентов используется морфологическое открытие:

```matlab
r = 20;

se = strel('disk', r);
```

Затем обработка выполняется отдельно для каждого среза.

После `imopen` выбирается крупнейшая связная компонента:

```matlab
CC = bwconncomp(slice);

numPixels = cellfun(@numel, CC.PixelIdxList);

[~, idx] = max(numPixels);
```

Полученный результат используется как маска артефактов:

```matlab
result(:,:,i) = cleanSlice;
```

После чего окончательная маска пор формируется:

```matlab
por = hullVolume & ~boneMask;
por = por & ~result;
```

И визуализируется:

```matlab
volshow(por);
```

# 14. Размер вокселя

Для расчёта физических размеров используется информация из `.VGI`.

Размер вокселя извлекается автоматически:

```matlab
expr = '(?i)(voxel|resolution|sampling)[^\d-+]*([0-9Ee+-.]+)';

tokens = regexp(txt,expr,'tokens');
```

Если значение найдено:

```matlab
dx = voxelSize;
dy = voxelSize;
dz = voxelSize;
```

Объём одного вокселя:

```matlab
Vvox = dx * dy * dz;
```

Если размер вокселя не найден, используются:

```matlab
dx = 1;
dy = 1;
dz = 1;
```

В таком случае результаты интерпретируются в единицах вокселей, а не в физических единицах.

# 15. Общие морфометрические параметры

Для бинарной маски пор:

```matlab
BW = logical(por);
```

определяются:

```matlab
bone = ~BW;
```

## Total Volume

Количество всех вокселей:

```matlab
TV = numel(BW);
```

Физический объём:

```matlab
TVreal = TV * Vvox;
```

## Bone Volume

Количество вокселей кости:

```matlab
BV = sum(bone(:));
```

Физический объём:

```matlab
BVreal = BV * Vvox;
```

## Pore Volume

Количество пористых вокселей:

```matlab
VV = sum(BW(:));
```

Физический объём:

```matlab
VVreal = VV * Vvox;
```

---

# 16. BV/TV

Относительный объём костной ткани:

```matlab
BVTV = BV / TV;
```

Параметр:

```text
BV/TV
```

характеризует долю объёма, занятую костной тканью.

---

# 17. Пористость

Пористость рассчитывается как:

```matlab
Porosity = VV / TV;
```

В процентах:

```matlab
Porosity * 100
```

То есть:

```text
Porosity = pore volume / total volume
```

---

# 18. Поверхность кости

Граница костной ткани определяется:

```matlab
boneSurface = bwperim(bone,26);
```

Количество поверхностных вокселей:

```matlab
Nsurface = sum(boneSurface(:));
```

Оценка поверхности:

```matlab
BS = Nsurface * Vvox;
```

Также рассчитывается:

```matlab
BSBV = BS / BVreal;
```

что соответствует отношению поверхности кости к объёму костной ткани.

> Примечание: в текущей реализации `BS` является оценкой поверхности через число поверхностных вокселей. Для строго физически интерпретируемой поверхности в 3D может потребоваться более точная voxel-surface или mesh-based методика.

---

# 19. Connectivity Density

Для оценки топологии используется характеристика Эйлера.

В проекте реализована собственная функция:

```matlab
bweuler3d(BW, conn)
```

Она использует локальные конфигурации `2×2×2` и таблицу коэффициентов для 26-связности.

Расчёт:

```matlab
eulerNum = bweuler3d(BW, 26);
```

Плотность связности:

```matlab
ConnD = (1 - eulerNum) / TVreal;
```

Полученные значения позволяют характеризовать топологическую связанность пористой структуры.

# 20. Watershed-сегментация пор

После получения общей маски пор выполняется разделение пор на отдельные объекты.

Сначала рассчитывается distance transform:

```matlab
D = bwdist(~BW);
```

Для уменьшения шумов используется сглаживание:

```matlab
D = imgaussfilt3(D,0.5);
```

Формируется отрицательная distance map:

```matlab
Dneg = -D;

Dneg(~BW) = -Inf;
```

Затем определяются маркеры:

```matlab
mask = imextendedmax(D,0.5);

mask = bwareaopen(mask,10);

markers = bwlabeln(mask);
```

После этого применяется Watershed:

```matlab
L = watershed(imimposemin(Dneg,markers));

L(~BW) = 0;
```

Получается 3D-разделение пор на отдельные объекты.

# 23. Радиус пор

Для каждой поры рассчитывается максимальное значение distance transform:

```matlab
poreRadius(i) = max(D(idx)) * dx;
```

Таким образом, `Radius` представляет собой максимальный локальный радиус, полученный из distance transform.

Рассчитываются:

```matlab
Rmean = mean(poreRadius);

Rmax = max(poreRadius);
```

# 28. Угол относительно оси Z

Для каждой поры вычисляется угол между главным направлением и осью `Z`:

```matlab
cosTheta = abs(dot(mainDir,[0;0;1]));

angleFromZ = rad2deg(acos(cosTheta));
```

Интерпретация:

```text
0°   → ориентация вдоль оси Z
90°  → ориентация перпендикулярно оси Z
```

Полученный параметр записывается как:

```text
Angle_Deviation_From_Z
```

---

# 29. Степень анизотропии

Используется:

```matlab
degAnisotropy = 1 - (l3 / l1);
```

где:

```text
l1 = первая главная ось
l3 = третья главная ось
```

Таким образом, показатель характеризует отличие формы поры от более изотропной геометрии.

Чем сильнее различаются главные размеры, тем выше значение данного показателя.

---

# 30. Сферичность

Для каждой поры оценивается площадь её поверхности:

```matlab
porePerim = bwperim(subPore,26);
```

После этого рассчитывается сферичность:

```matlab
sphericityVal(i) = ...
    (pi^(1/3) * (6 * volReal)^(2/3)) / poreAreaReal;
```

В идеализированном случае сфера имеет сферичность, близкую к `1`.

Более сложные или вытянутые формы имеют меньшую сферичность.

# 32. Открытые и закрытые поры

Для определения открытых пор проверяется, пересекается ли соответствующая label-компонента с границей исследуемого объёма.

Если пора достигает границы:

```text
Pore_Type = Open
```

В противном случае:

```text
Pore_Type = Closed
```

Таким образом, таблица содержит классификацию:

```text
Open
Closed
```

Важно учитывать, что в данной реализации **open/closed определяется относительно границы анализируемого объёма**, а не обязательно относительно всей биологической структуры.

# 36. Downsampling для визуализации

Если количество пор очень большое, визуализация всех объектов может быть медленной.

Поэтому используется:

```matlab
maxPoresToPlot = 3000;
```

Если пор больше 3000, выбирается случайная выборка:

```matlab
idx = randperm(numPores,maxPoresToPlot);
```

Это влияет **только на визуализацию**, а не на исходные расчёты.

# 39. Основные параметры, требующие настройки

Результат сегментации зависит от нескольких параметров.

## Threshold

```matlab
level = graythresh(V);
```

Используется автоматический Otsu threshold.

При необходимости можно заменить его на фиксированный:

```matlab
level = 0.35;
```

---

## Gaussian filter

```matlab
sigma = 0.7;
```

Используется при выделении границ.

---

## Минимальный размер объекта

```matlab
Vbin = bwareaopen(Vbin,500);
```

Число `500` необходимо адаптировать под разрешение томограммы.

---

## Alpha shape

```matlab
alphaValue = 15;
```

Этот параметр существенно влияет на форму `hullVolume` и, соответственно, на выделенное пространство пор.

---

## Morphological opening

```matlab
r = 20;
```

Большое значение может удалить реальные небольшие структуры.

---

## Watershed smoothing

```matlab
D = imgaussfilt3(D,0.5);
```

---

## Watershed markers

```matlab
mask = imextendedmax(D,0.5);
```

Изменение этого параметра влияет на количество разделённых пор.

# 40. Важные замечания по интерпретации

Пайплайн является **алгоритмом сегментации и количественного анализа**, поэтому численные результаты зависят от параметров обработки.

Особенно чувствительными являются:

* порог бинаризации;
* `sigma`;
* размер структурирующего элемента;
* `alphaValue`;
* параметры Watershed;
* минимальный размер компоненты;
* разрешение исходной томограммы.

При сравнении контрольной и экспериментальной групп рекомендуется использовать **одинаковые параметры обработки**, если это методически обосновано.

Например:

```text
Control
    ↓
одинаковый pipeline
    ↓
metrics_control.csv

Spaceflight / cSCI
    ↓
тот же pipeline
    ↓
metrics_cSCI.csv
```

Это уменьшает вероятность того, что различия между группами будут вызваны настройками алгоритма, а не особенностями образцов.
